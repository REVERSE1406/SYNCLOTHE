SYNCLOTHE STUDIO 2.0 · PROTOTIPO UNIVERSITARIO

Lee README.md para ver todas las instrucciones, funcionalidades y límites.

INICIO RÁPIDO:
1. Abrir esta carpeta completa en VS Code.
2. Con la extensión Live Server, abrir index.html (Open with Live Server).
3. Ir a «Mi calendario» > completar onboarding > «Probar con 6 prendas de muestra».
4. Crear un look con parte superior e inferior, guardarlo, asignarlo al calendario y registrarlo como usado.
5. Revisar las estadísticas y probar a editar el perfil.

Las fotos y datos se guardan localmente en IndexedDB; no hay pagos ni backend real.
